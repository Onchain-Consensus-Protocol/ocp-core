# Core 中途退出与公众提前终止申请

状态：本地实现候选。未部署、未发布；旧不可升级合约不受源码修改影响。仅在独立测试网入口接入新交互，默认纯模拟市场不切换。

## 用户确认的规则

- 中途只能全仓退出。罚没 `ceil(本金/10)`，退还剩余本金，即向下取整的90%；不再叠加此前暂停的1%提现费。
- 退出从本金分布、方向总额和参与人数中扣除；罚没资金不计入任何方向权重。
- 已累计的YES/NO/INVALID三套条件手续费权益分别冻结作废，小数也保留在对应作废记录，不将三套相加当真钱。
- 可以同地址重新参与并重新选边，新本金从新入场指数开始；不会恢复旧个人历史权益，但可作为新参与者分享终局奖励。这与多地址可能分回部分罚金一样，是已接受的机制边界。
- 最终YES/NO：罚没本金和失败提案保证金并入结算本金池，按最终赢家本金比例分配。INVALID：按全部剩余本金比例分配。
- 放弃的手续费只选择最终结果对应账，在原已收费用池内部重新分配给最终合格玩家。INVALID费用仍只给YES/NO；不发给INVALID质押者。独立bonus按终局本金比例分配，未重复增加手续费总额。
- 保留最后合格领取者收尾差的规则。若无人有资格领取费用，沿现有官方兜底；若完全无剩余本金，沿现有空池归集兜底，不除零或虚造玩家。

## 提前终止

- 任何人可以提交YES/NO；创建者无特殊直接终止权。
- 保证金统一500 USD。创建市场时使用抵押代币/USD价格和正确原生位数换算，向上取整并写入Vault immutable，之后不随Core本金或股价重定价。不是每次申请再用喂价换算。
- 固定1小时窗口，只有一份pending，不可撤销；剩余时间必须大于完整窗口。无Core本金时不接受申请。
- 窗口内可继续交易、同侧质押、按规则退出。原Formal截止仍有效，不因申请恢复本来已到期的交易。
- 到期后质押、退出及手续费入账必须先处理申请，Formal买卖/配对赎回也锁住；任何人可调用permissionless处理，不依赖特定Keeper权限。
- 到期Core严格多数与申请结果相同：按该结果冻结并结算。成功申请截止固定为窗口结束时刻，执行者晚调用不会改票数或截止。
- 不同（含INVALID）：罚没保证金，继续原期限内的交易/质押，可发新申请。若处理时已过原截止，则直接常规终局，不再恢复交易。
- 申请保证金不计投票权、不混入成功后的本金赔付。成功后全额记独立可领取退款，采用pull领取；收款方转账失败不会回滚公共结果处理。
- 原截止时间是最晚终局，提案不能延长它；没有更早pending时到期常规结算。有更早窗口的pending必须先按已冻结状态处理，不能因执行者晚调用跳过应有罚没或改变早结果。

## 独立提前终止模块

提前终止规则和申请状态已拆入 `TopicMarketEarlyTerminationModule`，统一工厂的 CoreDeployer 部署一份共享实现，每个市场创建独立的 EIP-1167 clone。模块只记录申请、保证金报价和窗口，不接收代币、不修改投票、不决定最终结果。

Core 保留保证金托管、失败罚没、成功退款、资金守恒及实际结果判定；前端仍调用 Core，避免两笔交易间出现未入账申请。Core 在申请前缓存模块报价，核对返回内容并原子扣款；处理时核对已托管保证金和模块消费的同一申请。

模块只能由 Core 调用，初始化只允许 Core 或其部署者，且只能执行一次。Core 只能在绑定市场前固定一次模块，之后没有管理员替换或升级入口。今后更换规则供新市场使用时，可修改模块及部署配置，保留 Core 的资金和判定接口；既有市场继续遵守创建时的规则。接口覆盖的窗口和保证金策略可以独立变化，涉及投票或赔付规则的改变仍需修改 Core。

默认模块仍使用固定1小时及创建时500 USD换算的保证金；Genesis 不开放提前终止。替代策略测试另用30分钟和两倍基准保证金，验证 Core 未写死这些策略参数。

## 合约与客户端

- Vault：exitStake/previewExitStake、proposeEarlyTermination、pendingEarlyTermination、earlyTerminationBondRequired、processEarlyTermination、claimEarlyTerminationBond。
- Adapter：处理申请失败时正常返回，不强制调用尚未可执行的Market.finalize；成功时可原子完成Core+Market结算。
- Market：单独检查tradingAllowed，不修改isFormalMarket“曾毕业”语义；终局信任已绑定Core结果及effective cutoff，去除必须等待原截止的旧硬锁。
- 创建码：CoreDeployer采用STOP前缀的两个不可变数据仓，避免把完整Core创建码嵌入运行时超过EIP170。数据仓不改变部署账户的nonce预测。
- 前端：仅testnet.html启用新退出/提案/处理/退保证金按钮。所有签名显式chainId46630、申请前精确授权、余额与状态检查；默认模拟入口保持原交互。
