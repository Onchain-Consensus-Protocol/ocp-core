# DLP-1 股票代币本位与稳定币路由设计补充

日期：2026-10-21。状态：用户确认的设计要求，尚未实现；不代表实盘就绪，不授权部署或发布。本补充覆盖旧规范中USDC作为唯一底层资产及目标链未定的描述；未冲突的曲线、费制、期限及结算规则保持。

## 2026-10-22 已确认：全部使用Uniswap V3

用户选择全部股票兑换统一使用Uniswap V3，不接V4。采用已在真实主网分叉验证的DLPV3Router02Exchange适配器，不能把旧classic DLPV3Exchange绑定到Router02。首期稳定币USDG，股票为官方TSLA/NVDA/AAPL/GOOGL/SPCX。每股票固定Factory/Router及单股票-稳定币池，初始费率基线TSLA3000（0.3%），其余500（0.05%）；费率池在部署前重新核对，不保证全部金额永久最优，不在运行时擅自变更已部署的不可变参数。配置见DLP_1_V3_ROUTING_CONFIG.json；真实分叉证据见RH_MAINNET_RESEARCH/RESULT_ZH.md。此选择不授权主网部署或发布。

## 1. 已确认范围

- 目标链选定为 Robinhood Chain。开发测试与生产网络须区分，不因选链而自动部署主网。
- 每个市场选择一种股票代币作为统一抵押、计价、费用及结算资产（下称C）。不是仅关联股票代码，也不是只在外部新增交易对。
- Genesis 的 R、B 为实际C余额；用户用C买卖gToken。毕业后gToken按占比转换为正式LMSR二元市场LP权益，B代币独立保留。
- Formal 以C买卖YES/NO，Core也以同一种C质押、本金记账及发放奖励。
- 用户可选择直接使用C，或使用支持的稳定币经兑换路由完成交易、质押及收款。稳定币不是另一个底层资金池，也不产生固定美元兑付承诺。
- 本设计不引入项目方强制补贴；兑换流动性须来自实际存在且可用的外部市场，不能假设永远存在。

## 2. 金额与现有机制

- Genesis二次储备曲线R=kS²、P=2kS保持。R及曲线成交金额的单位改为C；k的量纲、部署数值和展示面额必须重新校准，不能直接沿用USDC参数宣称价格一致。
- Genesis：买入实际收到X枚C，94.5%入R、4.5%入B并形成B贡献权益、1%创建者费用。卖出曲线毛额Y枚C，R减少完整Y，卖家94.5%、B4.5%、创建者1%。协议固定分成为0。
- Formal：交易本金/卖家98%、LP0.5%、B0.5%、Core1%；B新增费用不增发B代币。以上均以C计量，兑换费用不包含在这些比例内。
- Core按实际收到的C记本金；兑换前的稳定币金额不直接成为质押权重。现有多数、锁定、历史条件费用资格及无人合格质押的处理规则保持，未授权改成乐观预言机。
- 以1枚C作为一份结果份额的计价面额时，YES胜出兑付YES每份1C、NO每份0；NO反之；INVALID各0.5C。内部精度、面额及最小份额须统一实现，不得写成每份固定1美元。
- LP/B结算、首损、销毁领取、失败R及B固定快照清算继续以C执行，不能重复承诺同一资金。

## 3. 路由调用路径

| 操作 | 直接用C | 选择稳定币U |
|---|---|---|
| Genesis买入 | C→Genesis→gToken及B权益 | U→兑换C→Genesis→本人gToken及B权益 |
| Formal买入 | C→Market→YES/NO | U→兑换C→Market→本人YES/NO |
| Core质押 | C→Core，记录本人方向及本金 | U→兑换C→Core，记录本人方向及本金 |
| Genesis/Formal卖出 | 卖出净款C→用户 | 卖出净款C→兑换U→用户 |
| Core、市场及LP/B领取 | 结算C→权利人 | 结算C→兑换U→权利人 |

路由是兑换与业务调用的组合入口，不是新的裁决者或资金收益池。须由市场/适配器原生支持或验证用户授权，确保gToken、LP、B、YES/NO、Core方向与费用资格归属实际用户，不能记在路由地址后混同。现有v2.1主要基于msg.sender，不能直接把调用者换成Router就认为完成接入。

## 4. 执行与保护要求

- 同一笔组合交易原则上原子执行：兑换或业务调用任一失败，整笔回滚；不得部分收款后无权益、烧毁权益后无到账。
- 用户明确输入支付资产、金额、结果方向、收款人、最小兑换输出、最小业务输出/最大支付及交易截止时间。兑换滑点和曲线价格保护分别生效。
- 只按实际到账C计账；不靠价格预言机凭空发C。外部兑换报价、预言机估值、可执行成交价必须区分。
- 交易确认前展示兑换费用、外部价格影响、协议阶段费用及预计到账；报价过期须重新报价，不能保证固定稳定币金额。
- 可验证的市场、股票资产及兑换适配器范围；不接受任意外部调用任意目标/任意calldata。最小必要授权，重入保护，避免路由历史余额被下一用户取走；多余输入和dust归属必须明确。
- 稳定币兑换不可用、池深不足或资产暂停时，不得绕过最小到账保护。保留直接领取C的路径；C本身若被发行方暂停/冻结，路由不能保证转出。
- 不自动把跨链桥纳入兑换；第一版同链路由。主网真实DEX、代币地址及流动性须验证后才启用，mock测试不等同真实可用。

## 5. 精度、资产特性与门槛待落实项

旧实现固定USDC6，C不能假设6位；读验decimals、归一化、手续费舍入、最小金额及dust须覆盖。审查股票代币的转账许可、暂停/冻结、合约持有及DeFi组合限制、升级权限、拆股/反向拆股/分红或rebase等行为；未支持的行为不得默认兼容。

原毕业总目标4.2 ETH等值及R/B=3.6/0.6的经济比例保留。如何在创建时把ETH价值目标换算为固定C数量、所用可信ETH/C或组合价格源、新鲜度、股票非交易时段处理尚待确定；不得继续把ETH/USDC数值直接当作C数量。目标在创建后不随市价调整，具体精度及取整需定义。

Formal深度b的C本位数值、曲线k的C本位数值、gToken展示面额、支持的股票及稳定币清单、各资产合约与DEX路由/池地址均待验证定稿。本规范未指定第一支股票、稳定币或默认兑换平台。
