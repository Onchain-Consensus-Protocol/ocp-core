# 截止时间规则 v2.4

取代 v2.3 的独立截止设置。创建者仅指定最终截止 TC（Core 截止）：

- Genesis：创建时间 + 3小时。
- 正式市场：TF = TC − 1小时。
- Core 与话题最终截止相同，兼容字段 TT = TC。
- TC 必须晚于创建后4小时，保证 TF 晚于 Genesis 截止。
- 默认相对创建时间为 Genesis 3小时、Formal 5小时、Core 6小时。
- Formal 与 Core 仍仅在毕业后开启；提前毕业不重置截止。
- 存量多人模拟市场保留创建时已承诺的截止，不迁移。
- 不修改费用、毕业条件、LP/B 或结算经济规则。

合约 Factory、部署器、Market 创建接口仅传入 coreEnd；其余节点内部派生。合约源码已修改，本次不部署合约。
