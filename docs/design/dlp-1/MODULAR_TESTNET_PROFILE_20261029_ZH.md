## 提前终止的边界

统一工厂 → CoreDeployer（共享模块实现）→ 每个市场的 Adapter、Core 和独立模块 clone。

模块管理申请编号、申请内容、保证金报价、窗口和申请消费。Core 管理真实保证金、退款债务、罚没池、票数和终局结果。模块不持币，也没有选择结算结果的权限。任何人仍通过 Core 提交及处理申请；失败转账会原子回滚模块和账本。

每个市场绑定一次模块，不可替换，不提供事后管理员升级。未来新市场可以使用新模块策略，旧市场规则不变。Core 只校验资金、申请一致性及时间边界；默认1小时和500 USD创建快照是模块策略，替代策略测试覆盖30分钟及两倍保证金。改变投票或赔付方式仍属于 Core 的修改范围。

Genesis 不开放提前终止。默认模块的申请、失败罚没、成功退款与原有已确认规则一致，详见 CORE_EXIT_EARLY_TERMINATION_20261029_ZH.md。

## 测试网固定毕业门槛

`TopicMarketTestnetStockFactory` 只允许 chainId 46630；创建只接受 TSLA `0xC9f9c86933092BbbfFF3CCb4b105A4A94bf3Bd4E`，精度18。

- R达到0.0036 TSLA，并且B达到0.0006 TSLA，才毕业。
- 纯买入按当前4.5%贡献B，累计约0.013333333333333334 TSLA才能满足B条件；仅R达标不毕业。
- 这是固定测试门槛，不是对ETH价格的估计。记录的 `snapshot=0` 明确表示不使用ETH快照；Market构造再次独立检查链和资产。
- 标准 StockFactory 仍要求有效且非零ETH价格，主网原有3.6/0.6 ETH等值门槛不变。
- 500 USD申请保证金独立使用股票/USD价格，仍需有效喂价和已配置的sequencer检查；不能把低毕业门槛当成降低保证金。
- 前端识别固定profile，展示固定R/B并验证保证金USD换算，不因缺少测试ETH/USD轮次错误阻止创建。
- 部署脚本在46630强制该测试配置，其他链禁止启用；资产注册仍需实际可用的价格合约和路由。

既有链上不可升级工厂不会自动获得这些行为；本轮没有广播交易。
