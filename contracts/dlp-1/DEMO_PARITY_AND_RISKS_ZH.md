# DLP-1 合约与 Demo 一致性及保留风险

本说明以本目录合约和 `work/demo-publish/frontend/components/dlpDemoModel.ts`、`Simulation.tsx` 为比对基线。它说明已确认规则的实现边界，不代表部署完成、独立审计完成或允许接入真实资金。

## 一、已对齐的经济规则

- Genesis 从真实 R、B、供应量均为零开始，采用二次储备曲线；买入按净入 R 的金额计算铸造量，卖出按积分毛额从 R 全额扣除。
- Genesis 买卖均按 94.5% 本金／卖家实收、4.5% B 准备金、1% 创建者费用分配，无固定协议费用。实际 Genesis B 出资铸造对应 B 权益。
- 创建时固定 ETH 等值 USDC 快照，R 门槛为 3.6 倍快照、B 门槛为 0.6 倍快照。完整买单或卖单执行后，两池同时达标即原子毕业，不截断订单。
- 工厂创建采用三个固定截止：Genesis 为创建后 1 小时，Formal 为创建后 2 小时，Core 为创建后 3 小时。Formal 与 Core 在 Genesis 毕业时同时开启；未毕业则 Core 不开启。
- Formal 买卖按 98% 本金／卖家实收、0.5% LP、0.5% B、1% Core 分配；Formal B 费用增加真实准备金，不新增 B 权益权重。
- LP 底层资产锁定，中途不开放添加或退出；LP／B 为独立权益。完整 YES＋NO 组合可按规则兑换，单侧结果份额可正常买卖，不要求用户先拿另一侧。
- 结算时按最终结果计算库存价值，LP 净资产低于固定本金基准时，B 在自身余额内优先补损。LP、B 领取以固定快照分母计算，烧毁权益；先后领取不改变每份兑付率。
- Genesis 失败时，R 按失败快照中的 gToken 权益比例分配，B 按固定 B 权益比例分配；已经归属创建者的费用不退。不是按历史付款全额退款。
- Core 与市场资产独立记账。Core 为公开资本多数机制，账户选边后只能同侧追加，不能撤回或换边；市场价格本身不直接决定结果。未加入秘密投票或秘密换边规则。

## 二、本轮补齐的操作能力

- 增加工厂发射入口：调用者无需投入初始做市本金，只支付链上交易 gas；话题及 YES／NO／INVALID 定义与创建人、创建时间、价格快照一并登记。
- 提供按当前状态、分别假设 YES／NO／INVALID 的 LP／B 预计领取能力，使前端不需要自己重复实现结算分账；结算后以固定预算为准。
- 补齐统一领取入口，对应 Demo 的领取体验，同时保留独立权益领取入口。
- 增加适配器 `finalizeMarket()`，Core 截止后可由任何人一笔交易依次完成 Core 与市场结算；已结算部分跳过，调用者不能选择结果。链上状态变化仍由成功交易触发，不是后台时钟自动执行。

上述操作补齐不改变毕业门槛、费用比例、Core 结果规则或 LP／B 损益分配。具体 ABI、实现和验证以同目录源码及主 Agent 最终测试记录为准。

## 三、仍需理解的实现差异

| 项目 | Demo | 合约及接入要求 |
|---|---|---|
| 金额与精度 | JavaScript 浮点模拟 | USDC 六位整数、权益 WAD 精度；分账向下取整，报价存在微单位保护。极小单可能拒绝，最终可有不可分配 dust，不能保证逐位等于浮点。 |
| LP 余额出现方式 | 毕业立即把 gToken 转为账户 LP 余额 | LP 一次性铸入市场托管，按原始权益物化给本人；领取入口可完成物化。钱包余额与未物化权益必须合并理解，未物化不代表没有权利。 |
| 时间与自动执行 | 浏览器快进或定时更新 | 区块时间加显式调用。越过截止即禁止交易，即使尚无人调用关闭；关闭和结算仍需要发起交易、等待打包。 |
| 初始本金与真实成本 | 无真实支付 | 零初始本金不等于零 gas；用户还需代币授权和钱包签名。 |
| 外部直接转入代币 | 不存在该操作 | 用户可绕开业务入口直接转代币至合约。此类余额不是正常入账、LP 费用或 B 出资，不自动增发权利；不得用原始 token balance 替代分桶账本估值。无任意管理员提走款项的承诺。 |
| 权益转让 | 页面不展示 LP／B 转让、没有二级交易市场 | LP／B 底层仍是可转让 ERC-20；当前持有人拥有最终领取权。技术可转让不等于有买家、保证价格或可中途提取底层资产。 |
| 话题长度 | 表单可能以字符数或浏览器 length 限制 | 工厂按 UTF-8 字节计数：话题 1–512 字节，各结果定义 1–2048 字节。中文通常占多个字节，前端须按实际编码字节提示。长度限制不验证话题真实性或判定条件是否合理。 |
| 创建参数 | 演示参数可调整 ETH 快照、深度供体验 | 工厂固定 token、协议收款地址、k、深度和 Oracle；单个创建者不能自行传入价格、Core 或替换代币。 |
| 价格快照 | 手填演示 ETH 数字 | 真实 Oracle 获取 ETH/USD 与 USDC/USD 后换算，校验报价有效性并在创建时冻结；不是持续改变毕业目标。部署仍须确认链、feed 身份、heartbeat 及所需 L2 sequencer 策略。 |
| 费用角色 | 三个中立模拟账户，隐藏创建者／协议领取界面 | 创建者有 Genesis 费用领取权；Core 无合格奖励接收人的费用按既有 Core 官方接收规则处理。这不是重新新增 Formal 固定协议费。 |

源码若保留必须毕业／不得毕业的交易意图保护，这是链上可选执行约束；Demo 没有相同选择器。接入默认行为不应无意锁成“不得毕业”，也不得把此保护说成随机毕业。

Demo 历史代码中的池内 merge 分支，在 LP 锁定且无外部结果增发的合法持仓路径下不可达；本版合约不依赖池内 merge 提供单侧卖出。它不是要求用户先做成对赎回。

## 四、毕业时的权益估值断层仍然存在

这是当前确认机制的性质，不是本轮已经修复的经济问题。

设买入支付 X，进入 R 的净额 D＝0.945X，交易前后供应量为 S0、S1。毕业时，本笔新增 LP 对应的初始本金权益为：

`(S1 − S0) / S1 × R1 = D × S1 / (S1 + S0)`

接近毕业的小额买入中，该权益趋近付款的 47.25%，另有 4.5% 付款对应本笔新 B 权益的初始准备金价值。不能把曲线边际价格乘持仓直接当作毕业后的可领取资产。

合法数字路径：ETH 演示快照 2000，先纯买入，再由最后一笔 1000 dUSDC 使累计买入达到约 26,666.6667；毕业时 R＝25,200、B＝1,200，最后一笔之前 R＝24,255。

| 最后一笔买家项目 | dUSDC |
|---|---:|
| 支付 | 1,000.000000 |
| 新增 LP 对应初始本金权益 | 477.014743 |
| 本笔 B 出资对应的初始准备金权益 | 45.000000 |
| 合计初始权益估值 | 522.014743 |
| 与付款差额 | −477.985257 |

约 47.8% 的即时估值折价不等于已经确定的最终亏损：后续交易、LP／B 费用收入、做市结果和最终库存价值还会改变兑付。反过来，也不能保证后续收入一定弥补折价。此前已持有低成本 gToken 的人的整体成本和收益，需要合并其全部历史头寸计算。

双向毕业让后续卖单也可能结束 Genesis，但不会消除二次曲线边际价值转为按 R 份额权益时的估值变化。未经用户重新确认，不改变曲线、转换公式、收费或补贴规则。

## 五、自成交、关联创建者和 B 积累

从零开始买入 100，再卖出全部 gToken：

- 买入 R＝94.5，B＝4.5，创建者费用＝1。
- 全卖曲线毛额＝94.5；卖家实收＝89.3025，新增 B＝4.2525，新增创建者费用＝0.945。
- 合计 B＝8.7525，创建者费用＝1.945。

若最终 Genesis 失败，且没有其他交易、B 不发生其他损耗，交易者可通过卖出和 B 返还收回 98.055，损失 1.945；若交易者与创建者属于同一经济主体，创建者费用也内部回收，则系统外净成本可接近零，除 gas、整数舍入及资金占用。

这能制造交易量和 B 累积，不能据此证明话题存在独立真实需求。临近门槛还会承担意外毕业、资金锁定及 B 补损风险，因此不是所有状态下都可无风险抽走别人的钱。本轮未擅自加入身份审查、禁止关联账户或改变费用分配。

## 六、市场持仓与 Core 结果控制的条件性风险

Core 结果由公开资本比例决定，买有结果份额的交易者可以另外质押 Core。两本账分离不等于两个行为没有经济关联。

例如深度 b＝150，其他市场坐标为零，买入 100 YES：

- 曲线净成本约 58.183436。
- 按 98% 本金口径，支付约 59.370853。
- 若此后只有该交易者质押正数 YES，且截至 Core 截止无人反对，YES 达资本多数；100 YES 可领 100，Core 本金按胜方规则返还。
- 仅市场腿的付款与兑付差额约为 +40.629147；相关做市损益由 LP／B 按现行规则承担。实际数值还受整数舍入、参与者自己的 LP／B 权益和费用归属影响。

此例依赖“无人反对”等未来条件，不是确定性无风险套利，更不是凭空产生偿付资金。Formal 截止早于 Core 一小时，市场暴露已固定而 Core 仍可追加，持仓方有主动争取结果的动机。必须在真实运行前让参与者理解：本方案不是外部事实预言机结算。

未加入秘密投票、换边、结果外部仲裁或新的质押门槛；这些属于经济决策，不能作为普通修复悄悄实施。
