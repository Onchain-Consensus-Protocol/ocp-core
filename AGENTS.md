# Repository working notes

For OCP Genesis mechanism research or changes, read `.local/GENESIS_DESIGN_STATE.md` first when it exists. It records current decisions and distinguishes historical prototypes from the current design. Check actual code separately; neither a research report nor old implementation is proof of a newly proposed mechanism.

At the end of a research iteration, update the local design record with what passed, failed, or remains untested. Do not silently change confirmed economics or describe a partial mathematical test as production readiness. If the local record is absent, establish the current requirements from the user's instructions rather than assuming an old prototype was approved.

Preserve existing uncommitted changes. These working notes do not authorize deployment, publication, or a change to production economic rules.
