# 毕业连续性与最终赔付：隔离结算研究

日期：2026-10-29。范围：当前 `contracts/topic-market` 实际二次 Genesis、原双门槛、LP 锁定、B 首损。没有替换生产机制，没有部署或调用 RPC。当前源码指纹保存在配套 JSON，避免把以后改动当成本次所测代码。

## 结论

1. **当前毕业转换不满足净卖出价值连续。** 原可卖出的曲线凭证换成不能提前退出的 LP；即使先假设开放按 NAV 赎回，原曲线二次卖值和 LP 线性分配也不相等。这不是显示单位、手续费或调整毕业门槛能消除的问题。
2. **“毕业只换标签、保持相同资产及相同储备函数”确实能保证所有卖出数量的净报价连续。** 条件必须包括同一持仓、同一真实可用储备、同一费用及余数状态、无其他交易；不能换成 LP 后只继续显示原价。
3. **同一笔 R 不能同时支持不受限制的原曲线退出，以及另外发行的 YES/NO 最终赔付。** 如果把 R 完整留给原曲线，结果市场的最大损失必须由另外明确分配的真实资本承担，或由限制结果负债/改变退出权来补足。虚拟储备不能替代该资本。
4. 有一项**资金与毕业边界均自洽的研究构造**：保留原启动凭证及 R 曲线；现有 B 作为独立结果市场的首损资本，结果市场深度满足 `b ln 2 ≤ B`，B 权利只领取损失后的真实余款。无需创建者本金或项目补贴。但这改变当前 gToken 转 LP 的产品权利；gToken 与 YES/NO 必须分开，且结果市场深度显著低于当前 `b=R`。不是已完成的生产方案，也不能据此宣称所有底线已经实现。

## 1. 实际合约边界

- `TopicMarket.sol::_graduate()`：在末笔实付已经增加 R、B、S、用户持仓之后执行。把全部 S 铸成 LP，原 g 持仓按 1:1 映射为待物化 LP；R 全部转 `collateralCash`，生成等量 YES/NO 库存，`bWad=R*SCALE`。
- `quoteExit/exitLP` 明确 `LP_LOCKED`，所以毕业后没有对应的抵押资产即时退出报价。LP ERC20 可转让不代表存在有资金的买方或可执行二级池。
- 最终 LP NAV 为 `cash + lpFees + poolInventoryValue(result)`；B 仅补 `min(B,max(initialR−NAV,0))`，剩余 B 按原 B 权利分配。没有交易时库存始终为完整对，因此 YES/NO/INVALID 下 LP NAV 都等于 R，B 不需要补损。
- 本次读取的工作树还含 1% 项目出金费草稿。数值同时保留扣该费前后口径；毕业两侧使用相同费率、同一个初始费用余数，不用新增费用掩盖毕业差额。

## 2. 不是边际单价问题，而是整个数量区间的退出权问题

先忽略整型舍入，用正常资产单位写 `R=kS²`。冻结末笔已记账、尚未切换状态的同一经济持仓。卖出 `x=fS`：

```
原曲线毛退出 = k[S²−(S−x)²] = R(2f−f²)
原曲线扣原交易费后 = 0.945 R(2f−f²)
毕业后初始 LP 本金 NAV = Rf
```

共同的 1% 出金费进一步作用在两种金额上；差异仍存在。对足够小的 f，假设能按 NAV 退 LP，其净款仅为原净退出的 `1/(2×0.945)≈52.91%`。真实合约更严格：该 LP 退出入口根本不可执行，不能把“不可执行”说成存在 0 报价，也不能把 NAV 说成已可提款。

固定的 LP 面额重新缩放不改变 `Rf`。即使改成任意线性赎回 `v x`，要对所有 x 等于 `C(S)−C(S−x)`，也要求该区间 `C''=0`；当前二次曲线不满足。只对齐一个小单/一个数量点，不能推出其他数量连续。

同样不能把每个持有人独自卖出的反事实报价都登记为可同时领取的固定 NAV：持仓占比分别为 `f_i`、合计为 1，则曲线毛卖值之和为 `R(2−Σf_i²)>R`（存在多个持有人时）。这不证明曲线本身不守恒——他人卖出后 S、R 会改变；它证明不能把不同反事实状态的报价同时资本化成固定兑付承诺。

## 4. B 首损保证了什么，没有保证什么

令初始正式完整对抵押为 M，用户在外部持有结果份额对应的真实负债为 P(result)，池尚持有的结果份额终值为 `M−P(result)`。则：

```
LP NAV = cash + lpFees + M − P(result)
cover = min(B, max(M − LP NAV, 0))
LP payout = LP NAV + cover
B payout = B − cover
outcome payout = P(result)
合计 = M + cash + lpFees + B
```

这说明 B 与 LP/结果赔付没有重复花钱；不是另一份额外资产。也说明 B 不承诺 LP 永远不亏，更不提供即时退出：覆盖是终局一次补偿，当前 LP 仍锁定。若把 B 同时当全额可返本金和结果损失补贴，会再次重复承诺。

## 5. 标签不变曲线的充分条件与资金约束

持仓资产仍为原 g，卒业前后都调用同一个 `E(S,x)=C(S)−C(S−x)`，S、真实曲线储备、费用状态均不变，则任意 `0≤x≤持仓` 的净卖款严格相等。这是代数恒等式，不依赖边际近似；脚本的网格检查只是检查实现的研究函数没有因标签切换改变输出，**不代表 EVM 连续机制已实现**。

如果此时另外发行最终每份 YES=1 或 NO=1、INVALID 各 0.5 的结果权利，则必须为其保留真实履约资金。原曲线全量顺序赎回会消耗其自己的 R；把同一 R 同时视为结果负债的自由抵押，会令一个路径提款后另一个路径缺钱。应检验的是同时约束，而非“任一机制单独看有 R”。

若结果市场总真实资本为 L，用户交易净支付为 ΔC，结果负债为 `max(Y,N)`，必须满足：

```
L + ΔC(Y,N) ≥ max(Y,N)
```

标准 LMSR 的 `ΔC=b ln((exp(Y/b)+exp(N/b))/2)` 满足 `ΔC≥max(Y,N)−b ln2`，所以 `L≥b ln2` 是全域足额的简单充分条件。INVALID 负债 `(Y+N)/2≤max(Y,N)` 也被同一条件覆盖。

这里证明的是给定 YES/NO/INVALID 后足额赔付，不证明输入结果符合客观事实。当前 Core 按质押资本严格多数决定结果；若产品承诺客观真实事件，结果真实性仍须独立成立，不能由资金覆盖证明替代。

若不分出真正可承担损失的 L，却坚持原 g 全曲线退出和新结果赔付，则“毕业只改标签”不能凭空完成资金承诺。此结论针对同时保留这些具体权利；不是所有 Pump/连续预测曲线都不可行的证明。

## 6. 可计算的自筹构造：启动凭证与结果份额分开

**研究构造，不是当前代码。** 一个市场仍可以是一个界面/一个托管合约；这里分开的是资产权利和不可重复使用的账本，不要求额外项目补贴。

1. 启动层保持当前二次曲线凭证 g，R 真实支持其买卖。毕业只允许结果市场启动，不销毁 g、不改其净卖曲线、不把 R 改列为结果抵押。
2. Genesis 已实收的 B 继续归原 B 权利人承担风险；明确把其中 L 用作结果层首损资本，B 不是可同时全额退款的存款。取 `L=B`，`b≤B/ln2`。
3. 结果用户另行以真实抵押资产买入 YES/NO；其实际交易净支付 ΔC 与 L 一起支持最终负债。结果清算后，B 权利人只领取 `L+ΔC−P(result)` 的真实余值，交易费可按明确规则分配，不能向 g 再重复承诺 L。
4. 全部真实余额为 `R + (L+ΔC)`；两条义务合计为曲线实际退出资金加结果赔付及 B 余款，总和同样等于该余额。输出包含 9 组 YES/NO 持仓状态×3 结果检查。

本例 R=25200、B=1200：可用结果深度上限为 **1731.234049…**。若仍坚持当前 `b=M=25200`，即使保留当前每侧最多 M 库存，单侧库存用尽时所需首损资本也为：

```
M − M ln((e+1)/2) = 9573.114424…
```

仅 B=1200 仍短缺 **8373.114424…**；不能把保留给曲线退出的 R 再拿来填。无限库存标准上界更高，为 `25200 ln2≈17467.31`。因此不能既保留原曲线全退出，又不增资本、不变深度、还提供原正式市场全部风险承载能力。

### 这个构造的明确取舍

- **g 不再是即将变成 LP 的资产**，也不是胜方每份赔 1 的 YES/NO；它是保持同一买卖函数的启动/流动性凭证。不能用同一个“份额”名称隐藏两种权利。
- 结果市场的 B 出资方承受损失并获得余值，g 持有人不自动拥有当前方案的正式 LP 手续费与库存风险权益。分配收益可以另设计，但来源必须明确。
- 在已有 B 下，结果深度更浅；可选择进一步自筹资本、用户提供真实 LP 资本或限制结果市场风险。不能先写“深度不变”再把缺口留给未来买盘。
- **终局/失败规则仍须决策与验收。** 若期限一到强制把 g 改成 `R×持仓/S` 的线性清算，仍会在到期重现同类退出折价；毕业连续不等于到期连续。若保留截止后同曲线赎回，需要明确定价状态冻结、赎回次序、B/费用在结果清算后的归属与长期领取，不能直接套用当前固定快照并继续铸 B。
- 此构造证明“真实自筹+连续卒业+独立真实结果赔付”有资金上可行的路径，但并未完成产品期限、权限、合约整数化、状态机、攻击与需求验证，故不标为生产可用。

## 7. 可执行的最终判断

**拒绝作为修复结论：** 只改毕业阈值；只平滑显示价格；1:1 改面额；给 LP 开一个按 NAV 赎回入口；把 B 当额外免费保障；用后续买盘或未建立二级市场承接锁定 LP。它们均没有证明整个 x 区间净退出连续。

**能够解决毕业边界的必要方向：** 持仓与净卖函数在切换时保留，或者构造一个资金可承担、覆盖所有 x 的真实退出权映射。当前二次 g→线性锁定 LP 不属于这两者。若采用本报告的分层构造，先确认 g/结果份额的权利变化与更浅结果深度，再单独解决到期退出；不得直接改生产。
