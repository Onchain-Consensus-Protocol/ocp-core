# 毕业持仓连续性：资金与安全边界独立复核

日期：2026-10-29。只读审查生产候选，仅新增本文；未修改生产机制、未部署。依据当前 `contracts/topic-market/src/TopicMarket.sol` 及本地设计历史。当前二次 Genesis 候选与 `.local` 中历代连续曲线研究严格区分。

## 1. 当前真正可执行的路径

- Genesis `quoteGenesisBuy` 使用平方根增发，卖出毛额为 `k*(S²-(S-x)²)/curveScale`，原交易费后收款为毛额的94.5%；源码当前还有未完成部署的1%提现费草稿，属于另一个变更，不能把它当本报告新批准的机制。
- `_graduate`（315–335行）把现有g按数量变为LP，全部R变成完整YES/NO库存的抵押；不向Genesis用户发YES/NO，初始Formal `cash=0`。
- `quoteExit/exitLP`（524–525行）直接 `LP_LOCKED`。`materializeLP`只转出已托管LP ERC20，不支付底层资产。
- `formalSell`要求本人YES/NO余额；`redeemPairs`要求本人同时持有两侧。单有毕业LP不能使用它们兑现。
- `_claimLP`只在SETTLED执行，按固定毕业供应量分配最终预算。LP可转让只表示第三方可能愿意购买，不是协议保证随时存在买单。

因此当前同一Genesis持仓毕业后没有协议即时卖回路径。准确描述应是“暂不可执行”，不能伪造一个0价格，也不能用未成交的LP市场估值代替卖回现金。

## 2. 即使开放按比例LP退出，也没有修复平方曲线切换

忽略已单独列出的整数舍入，设毕业前刚完成末笔入账、尚未切换时：

`R = k*S²/D`，`x = α*S`，`0 < α <= 1`。

同数量g的Genesis卖出毛额为 `R*(2α-α²)`，原交易费后为：

`G(α) = 0.945*R*(2α-α²)`。

如果假设增加目前不存在的按比例LP退出，取回等量完整组合再赎回，且没有其他交易，所得只是：

`L(α) = α*R`。

所以 `G/L = 0.945*(2-α)`；当 `α < 2-1/0.945 ≈ 0.94179894` 时，切成比例退出会降低即时现金。

| 持仓占比α | 毕业前交易费后／R | 假设比例退出／R | 现金下降比例 |
|---|---:|---:|---:|
| 1% | 0.0188055 | 0.01 | 46.82% |
| 10% | 0.17955 | 0.10 | 44.31% |
| 50% | 0.70875 | 0.50 | 29.45% |
| 90% | 0.93555 | 0.90 | 3.80% |

两侧再收相同1%提现费时，上述比率在舍入外相消；不能拿提现费解释主体断层。B持仓原已存在且Genesis卖出还积累新的B权益，不能把不立即可领的B估值冒充当前卖回到账。

## 3. 对简单修法的严格判定

### 倍增LP：不增加权益；固定逐户现金：可能重复承诺

所有人LP与总供应同倍增加，所有份额比例不变。只增加某户份额会稀释别人；把不同单位换算成不同数量不增加真实资产。一个统一倍率也无法把对α呈二次式的G，变成对α呈线性的比例L，并同时匹配所有部分卖量。

如果把每户“毕业前单独整仓报价”固化成可同时兑付的现金债权，n户等分持仓时总承诺为 `0.945*R*(2-1/n)`，n增大趋于1.89R，超过R。这只否定**固定、同时可兑、按孤立报价逐户记债且没有新增覆盖资金**的补丁。

不能把这个求和用于否定共享曲线：真实顺序卖出会更新S/R，后续报价下降，整池按原曲线退出并不需要1.89R。保留同一可变曲线有可行资金基础，但不是比例LP退出。

### 调b：当前没有影响g即时退出的路径

b只控制Formal结果份额的成本/价格曲率。当前Genesis用户没有结果份额且LP锁定，改b不创造退出入口、现金或抵押。即使新增比例LP退出，没有其他交易时原有完整组合每对只兑一单位；b不改变αR。

历史 `.local/SAME_B_EXIT_CONTINUITY_RESULT.md` 讨论的是另一种“Genesis已持结果份额、同b去除outside状态”的研究模型，不能移植其不等式证明当前g→LP架构已连续。

### 动B：必须改变原权益与偿付承诺，不能同钱双付

当前B在终局先覆盖LP实际损失，再把剩余按Btoken分配。动用B可支持某个有限场景的额外现金，但必须同步核销B风险权益、LP覆盖与未来赔付责任。单纯多记一个“连续性补贴”却保留全部旧承诺，会重复占用同一资金。

这里不证明“任何B方案都不可能”，也不证明所有状态下B都不足；结论是既有双毕业门槛本身没有证明所需退出负债被覆盖，更没有授权无损挪用B。

## 4. 统一双侧结果token：可研究，但必须从首笔证明覆盖

设真实可用于结果赔付的资金W，三结果总负债分别为DY、DN、DI，必要条件始终是：

`W >= max(DY, DN, DI)`。

对于一份YES／NO分别在各自结果兑一单位、INVALID各兑半单位，条件化为 `W >= max(qY,qN)`；两侧债务互斥不是两份钱，但任何仍可即时提款的资本权益也不能重复承诺同一W。

**适用范围明确的不可能性：**零初始资金、无额外资本来源时，若第一笔允许单边发行q份固定一单位面额的结果token，而用户实际总付款小于q，YES或NO对应结果立即资不抵债。假定未来买家将补足不构成当期覆盖。这只排除这个具体组合，不排除所有Pump、可变面额、先由用户提供做市资本或先买完整组合等机制。

标准固定b LMSR未平移成本 `C=b*ln(exp(qY/b)+exp(qN/b))` 初始已有 `b*ln2` 资金需求；把成本减去初始常量让创建显示为零，不会取消其最大亏损。需要用户资本/真实费用等已明确资金来源，或者重新设计资本受限的曲线。低显示面额重定义不改变总负债。

可继续验证的方向是从首笔使用同一资产、同一储备和同一成本函数，毕业只开放功能，另证明每笔交易后上述覆盖不变量。必须检查单边第一笔、偏斜、完整组合、INVALID、贡献权益和结果权益同时领取、买卖往返、首次/末次参与者；不能只证明边际价不跳。

## 5. 保留Genesis资产独立：可修退出连续性，但需真实分账

保留同一g、同一S/R和同一卖出公式，毕业时不搬走其退出资金，可避免强制改变卖回公式。这与本地历史 `GENESIS_EXIT_REDESIGN.md` 的方向一致，但那份旧文档当时用的是另一条虚拟恒积曲线，不是当前二次候选的实现证明。

正式市场只能使用明确另行提供的资金（例如已说明风险和权益变更的费用资本、独立用户LP）。不能把同一R既保留给g卖出，又记成正式YES/NO的抵押；g持有者也不能同时拥有可无损领走该R的另一份LP权利。

若毕业后g只准卖不准买，它是顺序退出池，不满足“毕业后旧资产仍可继续双向交易并争取升值”的完整目标。若保留双向g交易，它与正式预测市场成为两个资产/流动性体系；需要明确g最终兑付、是否永续、无买盘时的退出风险，不能宣传g本身按真实结果固定面额赔付。

所以这是可以讨论的产品取舍，不是当前需求已经完整达成，也不是应直接部署的最小补丁。

## 6. 本报告范围与验收结论

目前可以确定：倍增全部LP、只调b、只改报价显示、把未来买盘当准备金均不修当前路径；无负债重算的B挪用有重复承诺风险。

没有证明所有Pump机制不可能。统一结果资产与独立保留g都有有条件研究空间，但尚未有满足用户全部目标、完整EVM生命周期和全域定点安全的生产方案。本报告未重新执行合约测试，数学式为明确假设下的解析推导；源码和本地历史记录分别核对，未把旧研究当当前实现。
