# 固定outside候选：安全与资金边界

2026-10-29。仅解析研究，不改生产；不把本候选当作已获部署批准。完整财富结论依赖尚未确定的资本／B分配与失败规则。

## 候选与真实资金来源

固定 `a>0,b>0`，`E=exp(qY/b)+exp(qN/b)`，`G=b*ln((E+a)/(2+a))`，`C=b*ln(E)`。从 `qY=qN=0,R=0` 启动。

Genesis买入总付U：R加`.945U`，B加`.045U`，创建者费`.01U`，但份额按`ΔG=.90U`发行。因此`H=R-G`每次买入增加`.045U=.05ΔG`。H是买家实付留下的资本，不是虚拟补贴；它在R内部，不能再算另一份钱。

Genesis卖出：R减`ΔG`，用户得`.945ΔG`，B得`.045ΔG`，创建者费`.01ΔG`。H不变。毕业需`R>=C`；毕业后标准C交易保持`R-C>=0`，三结果固定赔付覆盖成立，前提是不同时许诺另行无损提取该R的资本权益。

## 同数量净卖回连续性：成立的局部命题

对任意仍合法的相同持仓卖出路径，`dC/dq_i = exp(q_i/b)/E >= exp(q_i/b)/(E+a)=dG/dq_i`。因此固定q、b、a、无其他交易且同结果份额时，`ΔC>=ΔG`；Formal卖出保留98%也高于Genesis94.5%。同样提现费需独立展示，整数实现另行验证。

这个结论要求**真正保留同一种经济结果持仓和单位映射**，并不证明当前g→LP代码连续，也不证明终局资本权益无套利。

## 买入触发后立刻卖回：纯现金有严格上界

记`D=C-G=b*ln(E*(2+a)/(E+a))`。买前尚未达到覆盖条件，所以`H0<D0`；买后达标，所以`D1<=H1=H0+.05ΔG`。于是：

`ΔC=ΔG+(D1-D0)<1.05ΔG`。

整笔买入新发行的同数量份额毕业后立即反向卖回，Formal交易费后的现金小于：

`.98*1.05*.90U=.9261U`。

因此不能仅凭“毕业价格上跳”断言该笔买触发订单有立即纯现金套利。此界同时覆盖末笔大单；只卖出该单一部分不超过整笔毛卖回。它不包括该账户原有持仓、B权益、终局资本回收、其他人介入或多笔跨状态策略。

买入触发边界的局部导数还满足 `dD/dG=a/E<=.05`，边际价格倍率`C'/G'=1+a/E<=1.05`。拿低E处很大的潜在倍率当成买触发必然倍率，是错误反例。

### 保留其他毕业门槛时，上述界不能自动沿用

“还没产品毕业”未必意味着`R<C`。如果已足额，却因为另一项R/B门槛没到仍允许按G买卖，最终跨业务门槛的买单可以获得很大的确定现金补贴。

解析反例：`b=1,a=100,qY=qN=0,H=R=0.7`。此时已经覆盖`C(0)=ln2`，但假设R门槛是`.705`，B门槛已达，则仍处于Genesis。下一账户付`U=.01`买YES，`exp(qY)=102*exp(.009)-101`，得到`qY≈.6534409284`；R增至`.70945`并跨业务门槛。切成C后立刻卖回，毛额`ln((exp(qY)+1)/2)≈.3791702147`，Formal2%费后`.3715868104`，远大于`.01`。钱来自已有H，不来自新增价值。

H可由反复真实买卖留下：每一完整G往返使q回零、H增加`.045U`，B增加`.0855U`。例如累积H=.7时B=1.33，足以满足与R门槛成1:6的旧B门槛。选择每轮小额、保持R峰值低于业务门槛可以接近该状态；不能以“q回零所以R也零”排除此路径。更大的原R门槛可用更大已有H及接近门槛的小额最终单复现相同局部定价收益。

因此候选若保留原双门槛，必须另证约束或改变首次覆盖后的定价策略；不能把金融覆盖首次到达时的`.9261U`界当作无条件结论。正确实现还必须在卖中覆盖和交易前已覆盖时原子处理，避免同类延迟切换。

## 必须单独解决的边界

1. **卖中毕业真实存在。**卖出使E和D下降而H不变，原本`H<D`可变成`H>=D`；只检查买入会遗漏可毕业状态。卖触发倍率可大于1.05，必须将该笔正常卖出记账完成、转换前后的同一剩余持仓分开比较。
2. **Genesis尚未固定面额足额。**此时只保证`R>=G`，不保证`R>=max(qY,qN)`。同YES/NO地址也不等于从首笔就有一份固定兑一单位的无条件赔付权。若未毕业失败仍要固定面额赔付，本候选不能满足；若失败按G退出，则须明确这是条件性权利。
3. **全退出后H仍真实存在。**当q回零，G回零但R=H>0。H归谁、失败如何领、是否可持续交易必须确定。沿用旧g比例失败强平会重新制造曲线切换，q全零也不能除以零。
4. **B与资本权益尚未完整定义。**如果沿用买卖均铸z的规则，B包含买`.045U`和卖`.045ΔG`，H却只来自买`.045U`，两者不是同一本资本来源。不能在未定义剩余R、B、LP权益分配前宣称“全财富无套利”。
5. **大单跨门槛与时序。**明确是整单按G成交后转，还是在首个覆盖点部分成交再用C；两者产生不同份额／现金。已达标状态不应允许下一用户选择继续按G买入，否则会改变上述买前`H0<D0`假设。
6. **尚无EVM证明。**指数溢出、极偏斜log-sum-exp、接近门槛舍入与整数margin、跨阶段原子失败、零净卖出、固定截止、INVALID和B/资本同时领取均待完整实现验证。

结论：这不是“只改b”的假修法；它通过每笔买入明确减少可赎份额并形成真实H，提供了不同的资金机制。局部连续性与买触发立即现金往返有解析支持。未毕业固定面额、H归属、资本/B全财富与生产定点安全仍未解决，不能据此宣称所有用户目标已满足。
